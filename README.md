# Repaso ¡R

스페인어 문장과 단어를 듀오링고처럼 짧은 레슨으로 반복해서 외우는 웹앱.

- 문법 포인트별 학습 경로, 10문제 레슨, 틀린 문제는 다시 출제
- 문제 유형: 단어 고르기 · 단어 쓰기 · 알맞은 말 고르기 · 문장 조립 · 빈칸 쓰기
- 연속 학습일, XP, 하루 목표, 발음 듣기, 다크 모드
- 학습 기록은 브라우저(localStorage)에만 저장

## 세트
| 세트 | 내용 |
|---|---|
| ser vs estar | 두 가지 '~이다' 구분 (문장 50, 단어 86) |

세트 추가 방법과 데이터 형식은 [CLAUDE.md](CLAUDE.md)를 참고하세요.

## 실행
`index.html`을 브라우저로 열거나, `python3 -m http.server 8765` 후 http://localhost:8765
